# Scrcpy 新拟态远控助手 v3.2（单窗口实战可执行版）

针对您的反馈，本版本已彻底重构为 **紧凑单窗口桌面应用（475×820 竖屏精致单窗）**，并去除了所有虚拟演示画面，直接通过 Windows 原生进程接口调用您电脑上的 `adb.exe` 与 `scrcpy.exe`！

## 1. 如何使用（直接双击运行）
1. 解压压缩包后，直接双击运行 **`ScrcpyNeumorphicStudio.exe`**。
2. 程序将弹出一个独立的新拟态单窗口控制器，并在启动时自动执行 `adb devices -l` 检测您电脑上已连接的真实安卓手机、自动读取手机真实电池电量与温度。
3. **关于 `scrcpy.exe` 与 `adb.exe` 路径**：
   - 您可以直接把 `ScrcpyNeumorphicStudio.exe` 复制到您解压的官方 `scrcpy` 文件夹内（与 `scrcpy.exe`、`adb.exe` 同级目录）双击运行；
   - 或者点击界面右上角的 **齿轮设置按钮**，手动指定您电脑上 `scrcpy.exe` 和 `adb.exe` 的路径。

## 2. 单窗口 5 大实战功能页
- **【主控】**：中央圆形帧率表盘（点击切换 `30/60/90/120/144 帧/秒`）、分辨率选择、码率滑块、真实 **装应用 (`adb install`)**、**传文件 (`adb push`)**、**截屏幕 (`adb exec-out screencap`)**、**熄屏幕**，以及底部 6 枚真实硬件按键（电源、音量-、音量+、返回、主页、多任务）。
- **【参数】**：编码器 (`H.264 / H.265 / AV1`)、画面旋转锁定、窗口置顶、无边框模式、全屏启动、投屏自动熄屏、保持常亮、显示触摸点、关闭窗口自动锁屏、只读模式。
- **【无线】**：一键开启有线转无线 (`adb tcpip 5555`)、无线配对码配对 (`adb pair`)、无线 IP 直连 (`adb connect`)，以及安卓 11+ 系统声音/麦克风转发配置。
- **【录制】**：启动同步录屏 (`MP4 / MKV / Opus`)、安卓 12+ 手机摄像头直连 (`--video-source=camera`)、物理级键鼠模拟 (`UHID` 原生支持电脑中文输入法 / `AOA`)、纯 OTG 模式、新建独立虚拟屏。
- **【监控】**：真实手机电量与温度读取、帧率延迟趋势图、实时生成的完整 `scrcpy` 命令预览与真实进程标准输出日志。
